# OmniClip AI 🎬🚀

> **Turn 1 long video into 25+ viral social assets** across TikTok, Instagram, YouTube Shorts, LinkedIn & X with AI auto-cutting and auto-scheduling.

---

## ✨ Features

- ✂️ **AI Auto-Cutting:** Automatically identify and crop high-performing viral moments from long-form video content.
- 📱 **Multi-Platform Support:** Ready-to-publish exports formatted for TikTok, Instagram Reels, YouTube Shorts, LinkedIn, and X.
- 📅 **Auto-Scheduling:** Seamlessly queue and schedule your social clips directly from the dashboard.
- ⚡ **Blazing Fast Stack:** Built using Bun, TypeScript, and Vite for modern, high-speed development.

---

## 🛠️ Tech Stack

- **Runtime & Package Manager:** [Bun](https://bun.sh/)
- **Frontend:** TypeScript + Vite
- **Backend Server:** Node / Bun (`server.ts`)

---

## 🚀 Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/zeeshanriaz050-afk/omniclip-ai-.git](https://github.com/zeeshanriaz050-afk/omniclip-ai-.git)
   cd omniclip-ai-
Install dependencies:

Bash
bun install
Set up Environment Variables:
Copy the example environment file and update your variables:

Bash
cp .env.example .env
Run Development Server:

Bash
bun run dev
